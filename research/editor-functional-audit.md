# 编辑器功能与工程边界（2026-10-10）

本轮基于现有源码、公开画布快照和本地实现推进；用户已延期登录注册、小号和真实账号资源。浏览器使用实际页面组件和仅在忽略目录 `artifacts/` 中的本地用户夹具，未修改生产登录门槛，也没有向原站提交内容。以下验证确认本地能力，不等于原站登录态全部界面已精确复刻。

## 跨模块协议与持久化

- Skill 和 Canvas 的共享引用协议集中在 `src/services/agent-handoff.js`；Skill 原目录保留兼容导出。模型使用稳定 modelKey，Skill 使用 namespace/key，图片、视频、音频、文档包含可恢复的来源。
- session 暂存有效期为 30 分钟；Canvas 先成功保存本地文档再消费暂存。容量不足时保留暂存与输入，并提示失败。新交接文档以 draftPromptId 区分，避免所有新项目共用一个 key。
- 提示词编辑和移除引用会更新同一结构化草稿。复制、分享快照和 JSON 导出携带引用；普通空画布的未发送提示词也可保存。
- Canvas 与 Studio 自动保存使用有效的已加载文档标识。pagehide、组件离开时保存最后一次待写内容；加载失败或旧文档不会覆盖新项目。Studio 删除项目时清除待写保存，避免恢复已删除项目。
- Canvas 保留已保存的本地视口，不再被延迟的自动适配覆盖。中文输入法确认不触发 Agent 发送；未连接生成服务时保留提示词和参考，不假造生成结果。

## 公共弹窗生命周期

`useDialogBehavior` 与 `services/dialog-stack.ts` 统一管理站点 Modal、EditorDialog 和嵌入画布。只有最上层处理 Escape、Tab 与背景隔离；下层先卸载不会提前释放滚动锁。React 子弹窗先挂载时也保持正确层级。

回归覆盖嵌套/并列弹窗、下层先关闭、禁用或隐藏的回焦点目标、动态新增背景控件、原有 inert/aria-hidden 恢复。反馈 live region 保留可读。Canvas 快捷键不穿透弹窗；媒体预览的原生 controls 显式参与焦点循环。

## 3D GLB 实际恢复

旧实现把导入对象放入场景后只保存 data URL，刷新会使用默认几何体。现通过 GLTFLoader 从保存来源恢复实际层级、几何体与原材质；颜色覆盖撤销可以恢复原材质。异步加载检查文档/实体是否仍有效，删除或替换后不再添加迟到对象；卸载释放 geometry/material/texture。

导出等待恢复任务完成。读取错误明确提示，不能把失败解释为成功导入。当前支持 GLB 2.0 内嵌资源，文件上限 100 MB；不提供外部纹理文件、Draco/KTX2/meshopt 解码器，也未实现导入文件动画 clips 的完整播放和重新导出。文件可以因浏览器存储配额而无法持久化；错误必须可见，后续运营资源应使用服务器对象存储。

## 浏览器实测证据

桌面浏览器 1280×720，实际组件、本地演示用户：

1. Skill 描述点击打开详情，添加 Skill 后选择 Wan 3.0、输入提示词并上传图片。发送进入 Canvas 后四类 parts 可见；刷新保留模型、Skill、图片和原提示词。继续编辑、发送得到未连接服务提示，输入仍保留；再次刷新保留编辑后的文字。图片预览 Escape 关闭。Canvas 内 Agent 独立上传新增图片和音频，不创建画布节点，发送 parts 与刷新后的草稿均保留新参考。
2. 3.3 MB 图片触发 session 存储容量错误时，未导航、未清空输入；移除后改用约 34 KB 图片可以继续上述流程。此验证也说明 data URL 本地演示不能当成生产上传方案。
3. 导入包含橙色环面和蓝色圆锥的 GLB；修改位置、撤销、隐藏/恢复、删除/撤销均可见。保存后刷新仍恢复同一几何体与材质。浏览器导出 GLB 为 13,828 bytes，再导入新文档仍显示相同物体；控制台错误/警告为空。
4. 音频预览实测 Tab 路径：关闭按钮 → 原生媒体 → 播放 → 进度 → 音量 → 更多 → 回到关闭。公共弹窗的不可见 focus boundary 允许浏览器内部控件自然遍历，不会在媒体元素上过早循环。
5. 嵌入画布上打开外层站点 Modal：背景画布隔离，Modal 获得焦点；先关闭底层画布仍保持滚动锁，Escape 关闭顶部后恢复背景与滚动。

本地忽略目录证据：`artifacts/skill-canvas-reload-proof.jpg`、`artifacts/glb-reload-proof.jpg`、`artifacts/studio-import-fixture.glb`、`artifacts/studio-browser-export.glb`。这些是验收夹具与产物，不进入生产路由或运行内容。
