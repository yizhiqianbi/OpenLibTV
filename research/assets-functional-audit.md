# 资产库功能审计

更新：2026-10-11。本轮重构覆盖个人资产库的本地可操作流程。账号、注册与原站签入验收按用户要求延期；资产 CRUD 不调用原站写接口。内容使用本机夹具和既有代表性素材，不以内容数量作为功能完成条件。

## 依据与结构

原站公开客户端依据：`research/source/0qme_d9a8um1y.js`、`1s04obhd6gcqj.js`、`2jo-ap4o74v50.js`、`3vx5r5m_ep13u.js`，文案依据 `public/data/locale-zh.json`。这些证据支持个人素材库、目录、菜单、上传、标签和批量操作的客户端规则，不证明真实账号或服务器行为已经验收。

`src/services/asset-library/model.ts` 提供严格 TypeScript 记录类型、归一化和纯操作；`src/hooks/useAssetLibrary.ts` 统一存储边界；`src/features/assets/hooks` 管理页面操作与文件读取，`components` 管理卡片、菜单、目录树和弹窗，`domain` 管理真实下载与 Canvas 转交。UI 和控制器仍为 JSX/JavaScript，不能称为全业务 TypeScript 迁移。

canonical key 为 `libtv-asset-library`，版本 1，一次写入 `{assets, folders, tags}`。无 canonical 时兼容读取旧 `libtv-assets` 数组，保留旧 key 且不写回；成功保存后使用 canonical。解析、归一化、目录循环/缺失/超深等错误会显示并阻断写入，避免以空列表覆盖损坏数据；有效 canonical 不受无关旧 key 损坏影响。统一存储服务提供同 tab 订阅和跨 tab `storage` 事件更新。写入失败返回 false，弹窗保留输入和已读取文件。

## 已实现规则与流程

| 流程        | 当前行为及代码                                                                                                                                                                                                                                                                                                                                                                                                              |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 目录与名称  | 最多三级目录；文件夹名称去空白后 1–20 字符，资产名称 1–50 字符。创建/重命名/移动/删除均通过纯模型与统一 commit；移动保留子树，阻止自身/子目录目标、循环和超深。删除目录同时清除其旧软删资产，避免遗留失效 folderId。`model.ts`、`useAssetLibraryController.js`。                                                                                                                                                            |
| 列表与检索  | 300ms 防抖；有关键词时全库按资产名称检索，优先于当前目录和标签；无关键词时标签全局筛选，否则显示当前目录。初始 20 项，滚动或“加载更多”递增。目录面包屑和全局标签切换可用。                                                                                                                                                                                                                                                  |
| 菜单与批量  | 新建菜单 hover 80ms 打开、160ms 关闭，并支持点击；卡片更多菜单支持键盘移动、Escape/外点关闭。批量选中最多 300 个实际资产；选目录包含去重后的子树资产，支持部分选中，外部删除后过滤失效选择。重命名、移动、标签、下载、建画布、确认删除可操作。                                                                                                                                                                              |
| 上传        | 支持 JPG/JPEG/PNG/MP4/MP3 的源 MIME/后缀替代规则；单文件上限 `20 * 1024 * 1024` 字节（20 MiB，界面沿原文案写 20 MB）。FileReader 队列有读取/成功/失败、重试、移除和卸载取消，忽略迟到回调；读取中禁止保存。单文件改名按 upload.id 绑定，替换文件不沿用旧名。保存成功部分移出队列，失败部分留在弹窗可重试，不重复提交已保存文件。首次无目录时“待整理”文件夹与资产在同次 canonical 写入中创建；保存位置被删除时要求重新选择。 |
| 标签与预览  | 默认类型标签及自定义标签可选择、创建、筛选和批量替换。图片预览、原生视频/音频 controls、媒体错误重试可用；预览下叠加编辑弹窗保留媒体与焦点，关闭上层编辑返回触发按钮。                                                                                                                                                                                                                                                      |
| 拖放与下载  | 资产/目录可拖到目录或面包屑，使用同一移动校验。单文件下载真实资源；多文件用 Three.js 随附的 MIT fflate 生成真实 ZIP，同名文件不覆盖；请求失败/取消不保存部分下载，卸载中止请求。`domain/download.js`。                                                                                                                                                                                                                      |
| 创建 Canvas | 按实际资产 URL、mimeType、assetUuid 创建分开排列的媒体节点，先保存本地项目再导航；视口保存为 `{x:40,y:40,z:0.8}`，刷新恢复 80%。空媒体不打开伪项目。`domain/canvas-export.js`。可继续使用共享 Canvas Skill 创建 intake：清理一次性参数、选择当前画布、保存 blocked 请求；真实生成服务未接入，不假造 Skill 创建成功。                                                                                                        |

资产记录保留 id/name/type/mimeType/url/folderId/tags/assetType/createdAt/updatedAt，可选 bytes/thumbnailUrl/deletedAt；文件夹保留 id/name/parentId/createdAt/updatedAt，可选 coverUrl。上述 shape 是本地前端契约，未宣称已完成原站后台 wire 协议适配。

## 未完成与验收边界

原站签入状态、真实账号资产 CRUD、权限、服务器分页和跨设备持久化尚未验收或接入；本地演示成功不等于原站服务成功。Skill 和评论的后续浏览器记录位于对应审计。
